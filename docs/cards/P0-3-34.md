**🔴 最大坑（开工前就要知道）**

> **手工记录的分数会被下一轮同步悄悄抹掉。**
> Canvas 同步会照 `include[]=submission` 重写 `submission_score` / `points_possible`；
> 老师在 Canvas 上没登分 → 这两列的权威值是 `null` → 下一轮同步把用户刚填的 **9.5/10 覆盖回 null**，
