#### 🎫 P0-3-31 · 考试复习模式 v1（以考试为锚的复习包）⚪

- **做什么（Steven 原话）**：「点 Physics 7A Midterm 1 → 复习模式 → 从 Tempo 抓到的文件里选，还能上传额外文件
  → 用这些生成这次 midterm 的总结 / 试卷。**这个功能仅限归类为考试的。**」
  现有能力是**文件维度**（3-19b 一键总结 / 3-23 自测卷），没有一个以 `exam_dates` 行为入口的聚合。
  本卡建 `/courses/[id]/exams/[examId]/review`：① 考试信息（日期 / 倒计时 / 考纲摘录）② 按考试名推荐的
  已索引文件清单（可勾选）③ **上传额外文件**（Steven 已确认含此能力）④ 生成**本次考试的复习总结**
  ⑤ 挑中 past exam → 走 3-23 自测卷入口。
- **依赖**：P0-3-19 / 19b ✅、P0-3-23 ✅、P0-3-29 ✅（考试名归一可复用）、P0-3-30（可选：给出考纲范围）。
- **必读**：[`../Decisions.md`](../Decisions.md) **ADR-027**（只切用户选的题、**绝不出新题**）+
  **ADR-024**（懒生成 + 落库缓存）+ **ADR-026**（按需读取的三道闸门）。
- **grep 范围**：`lib/review/**`、`lib/practice-test/**`、`components/courses/**`、`app/(routes)/courses/**`。

**🔴 红线（沿用 ADR-027，不重新讨论）**

1. **总结** = 描述性提要，可以多文件合并（含 lecture / slide / pptx 都可）。
2. **试卷** = **只能**从用户选的那份 past exam（+ 它的 answer key）忠实切题，
   「照着这批资料再出一套题」**不做**（类型 B 已否，物理/化学会幻觉错公式）。
   复习模式里如果用户没挑 past exam，「试卷」按钮必须**不可用并说明原因**，不许悄悄降级成出新题。
3. 🔴 新增 message 类型 → **四处同改**（`types/message.ts` / `lib/messages/registry.ts` /
   迁移 CHECK / `regress-messages.ts`），加类型必同时补 applier + undoer（如有落点）。
4. 上传文件进 Storage 私桶，**只走会话 client，绝不用 service role**；越权判据同 3-19b 的双重防护。
5. 产物懒生成 + 落库缓存，**绝不进同步路径**（ADR-024 范式）；失败二分法同 ADR-026。
6. 标记一律打「AI 总结 / AI 生成」+ 保留「原文 ↗」。

**验收标准**

| # | 标准 |
|---|---|
| ① | 点 Midterm 1 → 复习页：考试信息 + 推荐文件清单 + 勾选 + 上传额外文件 |
| ② | 生成总结（多文件合并，标 AI + 原文链接）；二次进入命中缓存不重算 |
| ③ | 挑 past exam → 走 3-23 出卷，**题目全部来自那份卷**（对照 Slides-only 场景：试卷按钮不可用且有说明） |
| ④ | 跨用户隔离：A 用户传的文件与产物，B 用户打不到（Storage + 表双层） |
| ⑤ | 非考试任务不出现「复习模式」入口（Steven 明确限定仅考试） |
