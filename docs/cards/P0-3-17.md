##### 🔵 验收修正（2026-09-17，Steven 验收当天提出）

**「作业详情」只列已出分的作业** —— 原先列全部作业，没分数的行只是光秃秃一个标题，噪音大。

- 判据 = `submissionScore !== null && pointsPossible !== null`（与"分数条画不画得出来"是**同一个**条件，避免出现"列了但画不出条"的行）；
- **没分的行没有消失**：待办清单、周历、课程页其它区照旧可见 —— 这是"这一区不回答那个问题"，不是"藏起来"；
- 折叠标题同步改成「N 项已出分 · 共 M 项」（原先是「共 N 项 · M 项有分数」，展开只有 M 行 → 说的和看到的不一致）；
- 区块首行报「N 项已出分 · 另有 M 项暂无分数」，**只报数量不列行** —— 免得用户以为作业少了；
- 一门课还没出分 → 空态「这门课还没有出分的作业。Canvas 评分后会出现在这里。」；
- 连带删掉 `TaskRow` 里「已评分 · 分数未提供」那行提示：该状态已经不进这一区，分支不可达（死代码）。
- 改动文件：`components/courses/assignment-detail.tsx`、`app/(routes)/courses/[id]/page.tsx`（summary 计数）。

**分数条按分段上色**（同日第二处反馈）—— 原先整条一个中性蓝（`--chart-2`）。

- 档位（`scoreTone()`）：`>=100%` 绿 ｜ `90–99%` 蓝 ｜ `80–89%` 紫 ｜ `70–79%` 珊瑚 ｜ `<70%` 琥珀；
- 全部走主题令牌（`--chart-1..5` → `--purple`/`--blue`/`--green`/`--coral`/`--amber`），亮/暗主题自动跟随，**不写死 hex**；
- **🔴 最低档刻意不用 `--red`** —— 那是全站「缺交 / 逾期」的警示色，拿它画分数会把"这次没考好"和"出事了"混成一件事（ADR-013 的同一取向）。琥珀 / 珊瑚只是"另一档颜色"，不是"你完了"；
- 百分比数字保持中性灰（只有条上色）；`ratio` 已被夹在 `[0,1]`，加分项（`5/4`）归满分档；
- 产物 CSS 已验：`--chart-1:var(--purple)` … `--chart-5:var(--amber)` 与五个基础色均在，且指向主题变量（非硬编码）。
