> 新开 2026-09-23（P0-5 功能批次第 1 张，Steven 拍板插在 3-12/13 freeze 之前）。
> 状态：🔵 未开工。

## 1. 范围（Steven 已拍板，不擅自改）

先覆盖**核心四页**：

1. 登录 / 注册（`/login` `/signup`）
2. 总览 `/dashboard`
3. 课程列表 `/courses`
4. 课程详情 `/courses/[id]`

右上角加**语言切换按钮**：默认中文、可切英文；偏好存 **localStorage**（或用户设置，开工时二选一定死）。

**不要全站一次铺开** —— 其余页面后续按需扩。

## 2. 技术方案（开工第一步先定，写进本卡再动手）

- **首选**：JSON 文案字典 + React context（零新依赖）。
- **备选**：next-intl —— 仅当 context 方案在 Server Component 边界上撞墙才考虑；**别引重库**。
- 客户端要读的字典数据住**零依赖模块**（Next16 教训：Turbopack 挡不住客户端边界）。

## 3. 红线

- 🔴 **只动文案层**，绝不碰现有判定 / 状态模型：`isEffectivelyDone()` / `CANVAS_DONE_STATES` / `exam_key` 归一一律不动。
- 课程名 / 考试名 / 作业名是**用户数据**，不翻译（只有界面文案进字典）。
- Tailwind v4：新增类名要去产物 CSS 里 grep 验证（类名写了 ≠ 类被生成）。

## 4. 验收

1. 四页逐页切换中 / 英，无漏翻硬编码（grep 残留中文文案于这四页的组件层）。
2. 刷新 / 次日再访，语言偏好保留。
3. 门禁：`tsc --noEmit` + `eslint .` + `env -u NODE_OPTIONS npm run build` + 全部回归全绿。
4. 现有回归一条不许红（本卡不碰判定层，红了 = 误伤）。
