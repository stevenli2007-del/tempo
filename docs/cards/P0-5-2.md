# P0-5-2 · 课程详情页重构（Data C8 式左侧目录）

> 新开 2026-09-23（P0-5 功能批次第 2 张）。状态：🔵 未开工。

## 1. 做什么

课程详情页 `/courses/[id]` 从现在的单列滚动改为**左侧目录 + 右侧内容**：

- 四个 section：
  1. **Syllabus**
  2. **作业详情**
  3. **资料**
  4. **考试**
- 点「考试」→ 进**复习模式**（`/courses/[id]/exams/[examId]/review`，P0-3-31 已建）。

## 2. 红线

- 🔴 **只重构布局，不新增数据逻辑**：取数、判定、写入路径零改动。
- 复习数据键 = `(course_id, exam_key)`（🔴 绝不用 `exam_dates.id`，P0-3-31 教训）。
- 完成判定唯一来源仍是 `isCanvasDone()` / `isEffectivelyDone()`；空壳过滤仍走 `dropCanvasExamPlaceholders()`（3-36），重构时**不得另写第二份判定**。
- i18n（P0-5-1）已就位 → 新目录文案直接走字典，不留硬编码中文。

## 3. 验收

1. 四 section 点目录切换 / 锚点滚动正常；移动端有合理降级（目录可折叠）。
2. 「考试」入口可进复习模式，复习页数据与重构前一致（推荐文件 / 上传 / 总结 / 出卷全通）。
3. 现有功能回归：任务列表分组、成绩条、资料树、考试视觉（3-33）均不回归。
4. 门禁全绿（tsc / eslint / build / 全部回归）。

## 4. 依赖清单

- **必读**：`docs/cards/P0-3-17.md`（现有详情页结构）、`docs/cards/P0-3-31.md`（复习模式入口）。
- **grep 范围**：`app/(routes)/courses/[id]/**`、`components/courses/**`、`components/tasks/**`、`lib/review/**`（只读不写）。
