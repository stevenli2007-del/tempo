**实现要点**

1. `OnboardingStep` 新增 `media: { src, poster, caption } | null` —— **`null` 就不渲染**
   （指向不存在的文件等于画一个假东西，与「守卫判 null 时宁可不画链接」同一条纪律）。
2. 有动图的卡宽屏走**两列**（文字左、动图右），目的是让卡片**高度基本不变**，
   下面的「✨ 先看看效果」仍留在首屏（约束 ③）。窄屏退回单列，且**不给动图限高裁切** ——
   那会裁掉画面中间的对话框，正好是最该看的。
3. `autoplay` 三件套缺一不可：`muted`（不静音浏览器直接拒播）+ `playsInline`（iOS 否则强制全屏）+ `loop`。
4. 「减弱动态效果」**用纯 CSS 双元素切换**（视频 `motion-reduce:hidden`、封面图 `motion-reduce:block`），
   **不读 `matchMedia`** —— 后者要 `setState` 于 effect（撞 `react-hooks/set-state-in-effect`）且 SSR 会 hydration 不匹配。
5. 回归新增 20 条断言，最值钱的是 **`fs.existsSync`**：文件名打错时页面不报错、构建不报错，
   只是卡片上多一个空白框；另含体积闸门（单条 ≤700KB、封面 ≤120KB、合计 ≤2MB）。

**素材怎么来的**（原始 `.mov` 不进仓库 —— 二进制一旦进 git 历史就永久占位）

本机没有 brew/ffmpeg，用 npm 装一个静态二进制到 `/tmp`（不 sudo、不碰仓库）：

```bash
npm i --prefix /tmp/ffmpeg-tool ffmpeg-static
FF=/tmp/ffmpeg-tool/node_modules/ffmpeg-static/ffmpeg

$FF -i "原始A.mov" -vf "crop=1780:1258:420:640,scale=1200:-2,fps=15" -an \
    -c:v libx264 -crf 30 -preset medium -pix_fmt yuv420p -movflags +faststart \
    public/onboarding/new-token.mp4
$FF -ss 13 -i "原始B.mov" -t 21 -vf "crop=2584:1604:440:294,scale=1200:-2,fps=15" -an \
    -c:v libx264 -crf 30 -preset medium -pix_fmt yuv420p -movflags +faststart \
    public/onboarding/connect.mp4
$FF -ss 14 -i "原始A.mov" -frames:v 1 -vf "crop=1780:1258:420:640,scale=1200:-2" \
    -c:v libwebp -quality 82 public/onboarding/new-token-poster.webp
```
