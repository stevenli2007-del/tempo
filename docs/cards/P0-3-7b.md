#### 🎫 P0-3-7b · 总览页收纳：课程卡搬出 dashboard + 新建 `/courses` ✅ **已验收 2026-09-13（commit `ba361c4`）**

- **做什么**：Steven 看过 3-7 的真实渲染效果后提出的收纳诉求 —— dashboard 太长、3 张课程卡应该收进侧栏的一个独立栏目。原话设想是「在课程版面和设置隐私中间加一个**单科详情**，把课程卡都收进去」。
- **🔴 诊断（比"太长"更根本的一处错配）**：dashboard 的 `<h1>` 写着「我的课程」，可页面主体是**任务视图**（已到期作业 → 周历 → 待办清单），课程卡被挤到**页面最底部垫底** —— 标题和内容说的不是一件事，而且看一门课得先滚过整个任务区。
- **✅ 命名修正**：「单科详情」这个名字放错了位置 —— 单科详情页**早已存在**（`/courses/[id]`，点课程卡进去的就是它）。侧栏要加的那一项实际是**课程目录**，故定名「**我的课程**」。
- **✅ 两个决定（Steven 拍板）**：① 侧栏**单入口**「我的课程」→ `/courses` 列表页（**不**在侧栏内嵌课程列表：190px 宽的栏里课名会截断，课程增删还会让导航跳动）；② 课程卡**原样搬**、保持 2 列（零改造成本，且卡片上的 syllabus / 同步状态 / 近期任务在任务面板里看不到）。
- **✅ 连带改动四处（不改就断裂）**：① `CourseCreatePanel`（新建课程）**跟卡片一起搬** —— 否则 dashboard 有"新建"按钮却看不到列表；② `SyncControls`（同步）**留在 dashboard** —— 它服务的是任务数据，不是课程资产；③ dashboard 的 `<h1>` 改「**接下来**」+ 副标题改任务口径；④ `/courses/[id]` 两处「← 返回总览」改指 `/courses`，文案改「← 返回我的课程」。
- **🔴 最容易漏的一处**：侧栏高亮的 `match` 必须用**前缀匹配** —— 进 `/courses/[id]` 时「我的课程」要保持高亮，否则点进详情侧栏一片灰，用户会以为迷路了。已实测三页（`/dashboard` / `/courses` / `/courses/[id]`）**各自高亮正确**。
- **✅ 共享层抽取（本卡最该记住的一处）**：`formatDue` → `lib/tasks/format.ts`；`toUpcomingViews` / `groupBySemester` / `loadLatestSyllabi` → `lib/courses/course-list.ts`。**故意不在 dashboard 留副本** —— 卡片日期口径若存在两份，迟早出现"同一条作业在两个页面显示不同日期"，也就是第 18 条刚修过的 bug 在另一个入口原样复活。已落 `CodingRules.md §10.1` 第 20 条。
- **✅ 顺带的收益**：dashboard 不再需要「卡片近期任务」那一路查询（`loadUpcomingTasks`）—— **少发一个查询**；syllabus 查询与 `syllabiByCourse` / `syncLines` 的构造也一并消失。
- **✅ 自测**：`npx tsc --noEmit` 干净；`npx eslint .` 只剩 `theme-toggle.tsx` 一处**既有**报错；`npm run build` 通过（`/courses` 已进构建产物）。
- **✅ 运行时烟测（真实登录态，非"构建通过"）**：`/dashboard` **HTTP 200**、`/courses` **HTTP 200**、`/courses/[id]` **HTTP 200**，零服务端错误；`/dashboard` 上「近期没有待办」「新建课程」均 **0 处**（课程卡确已搬空），h1 已是「接下来」；`/courses` 渲染 **3 张课程卡**（＝ Steven 实际库内课程数；`13` 是 bCourses 侧的活跃课数，不是 Tempo 库内的门数）+「新建课程」按钮 + 删除按钮；侧栏三项 `href` 各命中 1 次。
- **验收路径（都能点）**：
  1. 侧栏现在是**三项**：课程面板 / **我的课程**（新）/ 设置与隐私 —— 点「我的课程」进课程列表页。
  2. `/courses`：3 张课程卡按学期分组 + 右上「新建课程」；点卡片仍进详情页。
  3. `/dashboard`：**滚到底再也不会出现课程卡** —— 页面只剩「已到期作业」→「接下来 7 天」→「待办清单」。
  4. 从任一课程详情页点左上「← 返回我的课程」→ 回到 `/courses`（**不再跳 dashboard**）；且**进详情页时侧栏「我的课程」保持高亮**。
- **⚠️ 排序纪律**：这是**结构**改动而非皮肤，**排在 P0-3-12 视觉扫尾之前**（先结构后皮肤）—— 否则 3-12 会从"扫旧样式"悄悄变成"重排信息架构"，那张卡就失控了。
