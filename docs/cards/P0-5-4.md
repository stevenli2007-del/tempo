## 1. 做什么

- 完成任务 / 考试 → 给「音符」储值（**累积展示**，纯数字，无兑换 / 无商城）。
- 完成动作发生时 → 放 **confetti 彩带**轻量正反馈（一次性动画，无需任何操作）。

## 2. 红线（ADR-016 / R5，本卡最容易翻车的地方）

- ⚠️ **ADR-016 hands-off**：操作量趋零才算成功。彩带是**被动的轻反馈**（完成动作顺带发生），**绝不**引入打卡 / 连续天数 / 每日目标 / 任何需要用户额外操作的机制。
- 🔴 **R5 禁庆祝性激励文案**：不出现「你真棒」「继续保持」「冲刺目标」类文案；彩带动画本身不带文字，或只带中性说明（如「+1」）。
- 音符只是**储值数字**：不绑任何第三方（无积分平台 / 无兑换 / 无社交展示）。
- 完成判定唯一来源 = `isEffectivelyDone()` / `isCanvasDone()`；**同步路径绝不写**用户主权字段（ADR-015）。音符计数的触发点写在「用户动作完成」处，不写在同步管道里（Canvas 代判完成要不要给音符：开工时找 Steven 拍板，默认**给**但零操作）。
- 展示位置克制：课程详情页（P0-5-2 新目录）或侧栏一处，不做弹窗轰炸。

## 3. 验收

1. 完成一条任务 → 彩带出现一次 + 音符 +1；刷新后数字保留（落库，RLS 两半）。
2. 全程**零额外交染操作**；重复触发（同一条任务重复确认）不重复计分（幂等）。
3. 文案层 grep 无 R5 违禁词；i18n 字典两语言同步。
4. 门禁全绿。

## 5. 实现留档（2026-09-24）

### 5.1 拍板：Canvas 代判完成**给**音符（Steven 2026-09-24）

选项问的是「`submission_state` 判定的完成、不是用户自己勾的，要不要给」。选了**给，但零操作**。
理由写在这儿是因为它反直觉：若只给手勾的，那么**同步越准、用户越不用来 Tempo，音符反而越不涨** ——
把 ADR-016 的核心指标（操作量趋零）变成了惩罚。判定因此**只能是** `isEffectivelyDone()`，
绝不另写 `status === 'done'`（`scripts/regress-notes.ts` 有 8 条断言钉着，含三个 Canvas 完成态）。

### 5.2 三个记入原则

| 原则 | 做法 | 为什么 |
|---|---|---|
| **幂等由结构保证** | `note_awards` 主键 = `(user_id, task_id)` | 靠"先查再插"守幂等，两个并发请求会都查到"没有"然后都插。主键冲突让第二次根本写不进去 —— 幂等是数据库的性质，不是某个函数的性质 |
| **不倒扣** | 取消勾选**不删行**，全仓没有 `.delete(` 路径 | 倒扣就是惩罚，ADR-016 R5 明令禁止。`awarded_at` 因此是"第一次完成于"，不是"当前状态" |
| **先查后插，不用 `upsert`** | 只 insert 缺的那几条 | `upsert` 会把已存在行的 `awarded_at` 刷新成现在；而总览页每渲染一次就懒补一次，用 upsert 那个"第一次"会天天变 |

### 5.3 两个记入点（共用同一个函数，别在别处另写 insert）

1. `PATCH /api/v1/tasks/[id]` —— 用户手勾完成，当场记一枚（此时才有彩带）。
2. `app/(routes)/dashboard/page.tsx` —— **懒补** Canvas 代判完成的那部分。
   刻意**不写进同步管道**：同步每轮都跑，等于把"每轮同步"变成"每轮写音符表"；
   且 ADR-015 规定同步路径不写用户这一侧的东西。放在读这一侧，用户零操作。

记入失败**不回滚**状态更新（状态是用户刚做的动作，音符是它的回声，主次不能颠倒），但必须留日志。

### 5.4 界面（克制）

- **展示只有一处**：侧栏底部 `♪ N`（`components/notes/note-counter.tsx`）。不弹窗、不进课程卡、不做等级 / 目标 / 百分比。
- **彩带零依赖、零操作**：`components/notes/confetti.tsx`，18 片确定性碎片（不用 `Math.random()` —— 随机值在 SSR 与首帧之间必然不同），
  整层 `pointer-events-none`，放完自卸；系统开了「减弱动态效果」就只保留读屏那句陈述。
- 🔴 **彩带不带任何文字**：R5 禁的是评价性激励。连中性的「+1」也没写 —— 数字会把注意力从"做完了"挪到"攒了多少"，
  那是储值化的第一步。读屏用户拿不到运动，另给一句陈述事实的 `sr-only`（「XX」已完成）。
