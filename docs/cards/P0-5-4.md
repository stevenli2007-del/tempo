# P0-5-4 · 音符储值 + 彩带动画

> 新开 2026-09-23（P0-5 功能批次第 4 张）。状态：🔵 未开工。

## 1. 做什么

- 完成任务 / 考试 → 给「音符」储值（**累积展示**，纯数字，无兑换 / 无商城）。
- 完成动作发生时 → 放 **confetti 彩带**轻量正反馈（一次性动画，无需任何操作）。

## 2. 红线（ADR-016 / R5，本卡最容易翻车的地方）

- ⚠️ **ADR-016 hands-off**：操作量趋零才算成功。彩带是**被动的轻反馈**（完成动作顺带发生），**绝不**引入打卡 / 连续天数 / 每日目标 / 任何需要用户额外操作的机制。
- 🔴 **R5 禁庆祝性激励文案**：不出现「你真棒」「继续保持」「冲刺目标」类文案；彩带动画本身不带文字，或只带中性说明（如「+1」）。
- 音符只是**储值数字**：不绑任何第三方（无积分平台 / 无兑换 / 无社交展示）。
- 完成判定唯一来源 = `isEffectivelyDone()` / `isCanvasDone()`；**同步路径绝不写**用户主权字段（ADR-015）。音符计数的触发点写在「用户动作完成」处，不写在同步管道里（Canvas 代判完成要不要给音符：开工时找 Steven 拍板，默认**给**但零操作）。
- 展示位置克制：课程详情页（P0-5-2 新目录）或侧栏一处，不做弹窗轰炸。

## 3. 验收

1. 完成一条任务 → 彩带出现一次 + 音符 +1；刷新后数字保留（落库，RLS 两半）。
2. 全程**零额外交染操作**；重复触发（同一条任务重复确认）不重复计分（幂等）。
3. 文案层 grep 无 R5 违禁词；i18n 字典两语言同步。
4. 门禁全绿。
