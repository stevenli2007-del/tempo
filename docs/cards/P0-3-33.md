- **做什么（Steven 原话 + 截图三张）**：①「考试和寻常任务要有区分」—— 周历里高亮了很好，
  但**今日任务列表**里考试和作业几乎没差别（只有个「考」字前缀）。②「不同学科区分不够，
  单单一颗很小的颜色亮点不足以区分」。③「登录页应该加我的水印：Build by Youcheng Li / UC Berkeley」。
  顺手带上 3-23 遗留：`material`（资料索引）消息同样是空写入却仍叫「确认」，应统一为「知道了」（R3）。
- **依赖**：P0-3-23 ✅、**依赖 P0-3-29**（先保证考试行的语义正确，再谈怎么画它）。
- **必读**：[`../CodingRules.md`](../CodingRules.md) §10（Tailwind v4 CSS-first）+ **ADR-017**（纯显示、GCal 也能做的 → 不做）。
- **grep 范围**：`components/**`、`app/(routes)/**`、`app/globals.css`。

**关键约束**

1. 🔴 **先结构与语义，后皮肤**：考试的**判定**只用既有单一来源（`lib/tasks/progress.ts` 与 exam 派生任务的属性），
   本卡只加视觉表现，**绝不新增第二套「这是不是考试」的判断**（同类教训见 3-15：判定分叉会让 40/83 条画错）。
2. 🔴 **Tailwind v4：类名写了 ≠ 类被生成**。课程色是运行时值，
   **不能拼 `bg-${color}`** —— 要么在 `app/globals.css` 的 `@theme` 里静态声明，要么走内联 style。
   验收必须 grep 产物 CSS 证明类真的存在。
3. 考试视觉语言**全站一致**（周历 pill / 今日任务行 / 课程详情 / BOX）：统一用「边框 + 底色 + 图标」三件套，
   而不是再加一个字。
4. 水印只加登录页（`app/(auth)/login`），**不许全站铺**（admin 味，且与 hands-off 调性冲突）。
5. `material` 按钮文案改动**必须同步改 `regress-messages.ts` 里钉住它的那条断言**（3-23 故意没动的那条）。
