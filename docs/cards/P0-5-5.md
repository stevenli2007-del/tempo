# P0-5-5 · 收尾遗留（3-35 / 3-36 归来的真根因）

> 新开 2026-09-23（P0-5 功能批次第 5 张）。状态：🔵 未开工。
> 三项都是 P0-3-35 / 3-36 验收时查实、但明确移出那两张卡的真根因收尾。

## 1. 三项范围（Steven 已拍板）

### ① 公告 PDF 附件里的考试地点解析

- 现状：`exam_dates.location` 两行皆 null —— Chem 1A「Exam 1 Locations」座位公告的地点在 **PDF 附件**里，附件内容从未进库（消息 `46d32653` 溯源结论）。
- 做法：公告带 PDF 附件时，按需路径拉取附件 → 抽文本（`unpdf` 四条硬约束见 `TechStack.md` §2）→ 解析地点 → 提案进消息栏 → 确认后写 `exam_dates.location`。
- 🔴 **ADR-026**：按需读取那一个文件，原文不落库 / 不落盘 / 不进日志；同步路径零下载。
- 懒生成范式（ADR-024）：不进同步路径，打开消息栏后触发，失败落 `failed` 不重试。

### ② 作业改期从公告路径走通

- 现状：公告解析出改期意图时只回「请用对话框确认」（P0-3-36 卡面 §4 已记档）；且 Canvas 来源的行直接写会被下一轮同步改回去。
- 做法：公告提案支持对**手动 / exam 来源**行的 due date 更新提案（复用 3-29 的 `resolveExamTargets()` + `applied` 旧值快照 + 撤销写回旧值）；**canvas 来源的行不写 due date**（写回去必被同步抹掉——要么提示去 Canvas 改，要么提案文案如实说明）。
- 🔴 改期 = **更新那一行**（按考试名归一命中），绝不并列新增（3-29 红线）；0 命中同日 = ambiguous 让人挑（3-36 红线）。

### ③ 提醒邮件列表过空壳过滤

- 现状：提醒邮件（P0-3-14）的任务列表没过 `dropCanvasExamPlaceholders()`，Canvas 空壳占位行会进邮件。
- 做法：邮件组装处调用同一份过滤函数（**唯一判据**，不得另写「名字像考试就隐藏」）。

## 2. 验收

1. ① 用真实公告（Chem 1A 座位公告可作测试数据，测试后**零残留清理**）：location 提案出现 → 确认 → `exam_dates.location` 落库 → 撤销写回 null。
2. ② 造一条改期公告 → 消息栏出「更新 旧 → 新」→ 确认后行数不变、日期变；24h 内撤销还原。canvas 来源行给出如实说明、不写库。
3. ③ 播种一条空壳占位 → 触发提醒组装 → 邮件列表不含该行 → 清理播种。
4. 幂等：公告解析连跑两轮，第二轮零新提案。
5. 门禁全绿 + 三把文档闸门全绿；不可逆操作（如有）先问 Steven。
