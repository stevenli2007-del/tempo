# P0-5-3 · 外部课程网站链接监控

> 新开 2026-09-23（P0-5 功能批次第 3 张）。状态：✅ **已验收（2026-10-04）** —— 六条走完 + 零残留，证据见 §5。

## 1. 做什么

用户在课程里贴**外部课程站点链接**（教授个人页 / 课程公告页等）：

1. 存 DB（新表或复用，开工时按 `Database.md` 定，迁移走 Dashboard、先 SQL 后部署）。
2. 定时重抓（**每日一次，Vercel Cron**；Workers Paid 出站能力见 `TechStack.md` §8）。
3. 抓取文本与上次快照**比对** → 有变化 → 进**消息栏**（复用 3-18）。

**只报「变了 / 哪块变了」，不做全文摘要。**

## 2. 红线

- 🔴 **ADR-026**：绝不下载原文落库 —— 比对用的快照只存**归一化文本摘要指纹**（如分段哈希），原文不落库 / 不落盘 / 不进日志，三道闸门在发请求前。
- 🔴 **不逆向第三方**（ADR-013）：只抓用户显式提供的公开 URL，不做登录态抓取、不做绕过。
- URL 守卫复用现有两分的任一语义：外链只放行 http(s)（`sourceUrl` 同款）；**禁内网 SSRF**（3-27 护栏复用：169.254 / 10. / 127. / 172.16-31 / 192.168）。
- 抓取失败**静默降级**（R3：失败要可见——消息栏状态或课程页标注，不无声消失）。
- 变化提案进消息栏 = 只追加、确认才写（ADR-015）；本卡大概率**零写入落点**（只报变化），若需写库走 applier + undoer 四处同改。

## 3. 验收

1. 贴链接 → 元数据落库（RLS 两半验证：anon 读空 + 真实会话读得到）。
2. 手动触发一轮重抓：无变化 → 零消息；造一处变化 → 消息栏出「变了 + 哪块变了」。
3. **幂等**：连跑两轮，第二轮零新消息。
4. 内网地址 / 非 http(s) 拒绝；抓取超时 / 非 200 不崩、状态可见。
5. 生产端点无凭证探针 **401 = 已上线**（`gh api .../commits/<sha>/status` 佐证）。
6. 门禁全绿 + 三把文档闸门全绿。

### 5.2 🔴 验收中查实的真事实（不是 bug，但要记住）

**GitHub raw（gist）有 300 秒 CDN 缓存。** 改完测试页立刻触发，连续三轮（21:31 / 21:32 / 21:35）都报「无变化」；直到**改后 366 秒**（21:37）那一轮才检出变化。

- **含义**：能多快检出变化 = **对方站点的缓存时长**（不是 Tempo 的抓取间隔说了算）。对「每日一次 Cron」毫无影响（间隔 ≫ 300s）。
- **验收手法要改**：用 gist / raw 这类带 CDN 缓存的源「造变化」时，必须**等过缓存窗口**再触发；想立刻看到，得换不缓存的源。
- ⚠️ 反面教训：本地 `curl` 在改后 8 秒就拿到了新内容（本地 CDN 节点预热更快）—— **不能用「我浏览器能打开新内容」反推「服务端也拿到了」**。
