- **① 文件夹树**：`lib/course-files/grouping.ts` 删掉 `groupByFolder()`（只按一层 `folder_path` 分组），
  改为 `buildFileTree()` → `CourseFileNode { name, path, files, children, totalCount }`。
  - 数据源是 Canvas 的 `full_name`（扁平路径串），按 `/` 逐段建节点；根目录文件挂在根节点。
  - **自然序**（`localeCompare(a, b, { numeric: true })`）—— 否则 `Unit 10` 会排在 `Unit 2` 前面。
  - `totalCount` **自底向上**累加（含子文件夹），UI 显示「Unit 1 · 10 项」而不是只数本层。
  - UI 用原生 `<details>/<summary>` 递归（`components/courses/course-files.tsx`）——
    零 JS、零 state、天然可折叠；`COLLAPSE_THRESHOLD = 20` 时默认收起。
- **② 一键总结**：每个文件行右侧加 `<Link prefetch={false}>` → `/courses/[id]/files/[fileId]`。
  - **🔴 红线开口有边界（ADR-026）**：**索引路径（同步）依旧零下载**；新增的**按需路径**允许下载
    **那一个**文件、抽文本、调模型，只把**总结**落库，**原文字节与抽取全文绝不落库、绝不落盘、绝不进日志**。
  - **🔴 Canvas 的 `url` 是能力凭据（capability URL）**：实测**不带 Authorization 头直接 GET 也 200 返回文件本体**
    → 既**不进库**（`course_files` 无此列）也**不下发客户端**，只在服务端当次请求内即时解析用完。
    下载端点也必须用单文件端点返回的那个 `url`（试 `/api/v1/courses/:cid/files/:fid/download` → **404**）。
  - **三道闸门都在「发请求之前」判**：扩展名/MIME 白名单（`lib/course-files/extractable.ts`，后缀优先、MIME 回退，
    真例 `Weekly Review 1 - PDF` 没有后缀）→ 库里 `size_bytes` 超限（`MAX_DOWNLOAD_BYTES`）→ 缓存命中且 `modified_at` 未变。
    **图片/音视频/压缩包在这一步就被判掉**，不下载、不调模型。`size_bytes` 为 `null` 时**不下载**（判不了成本宁可拒绝）。
  - **失败二分法**：**确定性失败**（不支持类型 / 超限 / 模型输出不合法 / PDF 无文本层）→ 落 `failed` 行**不再重试**；
    **暂时性失败**（网络抖动 / 模型 5xx / 限流）→ **不落行**，下次点击自然重试。用户看到的都是同一句话。
  - **越权双防**：RLS 查不到 → 404；查到了但 `target.courseId !== id` → 404（防跨课直链）。
  - **界面红线**：永远标「**AI 总结**」+「机器生成」徽标；永远保留「**原文 ↗**」；截断时显式警告。
